# أخبار البكالوريا المصرية

منصة عربية متجاوبة لمتابعة أخبار البكالوريا المصرية والقرارات التعليمية. تتضمن:
- واجهة أخبار عربية RTL تعمل على الهاتف والكمبيوتر.
- تجميع أخبار عبر Google News RSS وفق كلمات مفتاحية.
- تحديث RSS تلقائيًا كل 15 دقيقة (قابل للتغيير).
- تحديث واجهة الزائر كل 5 دقائق.
- بحث وتصنيفات.
- لوحة إدارة محمية بكلمة مرور لإضافة الأخبار اليدوية ومراجعتها وتثبيتها وحذفها.
- تخزين ملف الأخبار في مجلد بيانات قابل للاستمرار على الاستضافة.

## المتطلبات

- Node.js 20 أو أحدث.
- npm.
- استضافة Node.js تدعم متغيرات البيئة وقرصًا دائمًا لحفظ البيانات.

## التشغيل محليًا على Windows

1. فك ضغط الملف.
2. افتح المجلد في VS Code.
3. انسخ `.env.example` وسمّ النسخة `.env`.
4. افتح `.env` وضع كلمة مرور طويلة وفريدة في `ADMIN_PASSWORD`.
5. افتح Terminal داخل المجلد وشغّل:

```bash
npm install
npm start
```

6. افتح `http://localhost:3000`.
7. لوحة الإدارة: `http://localhost:3000/admin.html`.

## النشر على الإنترنت باستخدام Render

1. أنشئ حسابًا على GitHub وارفع ملفات المشروع إلى مستودع جديد. لا ترفع ملف `.env` أو مجلد `data`.
2. افتح Render وأنشئ **New Web Service** واربط مستودع GitHub.
3. Render يقرأ إعدادات `render.yaml`. إذا أدخلت الإعدادات يدويًا استخدم:
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Health Check Path: `/api/health`
4. أضف متغير البيئة `ADMIN_PASSWORD` بقيمة طويلة وفريدة لا تقل عن 14 حرفًا.
5. تأكد من إعداد قرص دائم (Persistent Disk) على المسار `/var/data`، لأن الأخبار اليدوية محفوظة في ملف JSON. إعداد القرص قد يتطلب خطة مدفوعة حسب سياسة الاستضافة الحالية.
6. بعد اكتمال النشر افتح رابط Render الذي تحصل عليه، ثم أضف `/admin.html` للوصول إلى لوحة الإدارة.

> تنبيه: لا تعتمد على نظام ملفات مؤقت في الاستضافة لحفظ الأخبار اليدوية؛ قد تُمسح البيانات عند إعادة تشغيل الخدمة. استخدم قرصًا دائمًا أو انقل التخزين إلى قاعدة بيانات مُدارة.

## إعدادات البيئة

| المتغير | الاستخدام | القيمة الافتراضية |
|---|---|---|
| `PORT` | منفذ السيرفر | `3000` |
| `ADMIN_PASSWORD` | كلمة مرور لوحة الإدارة | مطلوب |
| `DATA_DIR` | مكان حفظ ملف الأخبار | `./data` |
| `NEWS_REFRESH_MINUTES` | فترة تحديث RSS بالدقائق | `15` |

## نقاط مهمة عن دقة الأخبار

- الأخبار التي تأتي من RSS تظهر باعتبارها أخبارًا مجمعة وليست بيانات حكومية مؤكدة.
- لا تستخدم كلمة «رسمي» لخبر لم تتم مراجعته من موقع الجهة الحكومية أو بيانها الأصلي.
- روابط RSS قد تتغير أو تتوقف أو تتأخر، لذلك لا يوجد ضمان أن كل خبر سيظهر.
- راجع دائمًا موقع وزارة التربية والتعليم: https://moe.gov.eg/
- احترم شروط استخدام الناشرين وحقوق المحتوى. يعرض الموقع العنوان والملخص المتاح والرابط إلى المصدر بدل نسخ المقال كاملًا.

## الأمان

- استخدم HTTPS على الاستضافة.
- اختر كلمة مرور طويلة وفريدة، ولا تشاركها.
- لا تضع كلمة المرور داخل ملفات JavaScript أو HTML.
- غيّر كلمة المرور من إعدادات الاستضافة عند الحاجة.
- لا ترفع `.env` أو أي أسرار إلى GitHub.
- لوحة الإدارة تستخدم مفتاحًا يرسله المتصفح مع طلبات الإدارة؛ سجّل الخروج بإغلاق التبويب المشترك، ولا تستخدم لوحة الإدارة على جهاز عام.

## API

- `GET /api/health` حالة الخدمة.
- `GET /api/news` جميع الأخبار.
- `GET /api/news?category=قرارات%20الوزارة` تصفية حسب التصنيف.
- `GET /api/news?search=امتحانات` البحث.
- `GET /api/status` حالة التحديث.
- `POST /api/admin/login` التحقق من كلمة المرور.
- `GET /api/admin/news` الأخبار اليدوية (يتطلب `x-admin-password`).
- `POST /api/admin/news` إضافة خبر يدوي.
- `PATCH /api/admin/news/:id` تثبيت خبر أو وضع علامة مراجعة.
- `DELETE /api/admin/news/:id` حذف خبر يدوي.
- `POST /api/admin/refresh` بدء تحديث RSS.
